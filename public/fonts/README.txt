===========================================================
INSTRUÇÕES PARA A FONTE TT BACKWARDS
===========================================================

A fonte TT Backwards é uma tipografia comercial desenvolvida pela TypeType.

Para utilizá-la diretamente no projeto com fidelidade total:
1. Copie os arquivos da sua licença da fonte TT Backwards para esta pasta (public/fonts/).
2. Os formatos suportados e nomes esperados são:
   - TTBackwards-Bold.woff2 (ou .woff, .otf, .ttf)
   - TTBackwards-Regular.woff2 (ou .woff, .otf, .ttf)
   (ou simplesmente TTBackwards.woff2 / TTBackwards.otf / TTBackwards.ttf)

O projeto já está 100% configurado com @font-face no CSS:
assim que qualquer um desses arquivos for colocado aqui, a fonte será
carregada e aplicada instantaneamente a todos os títulos!
===========================================================
